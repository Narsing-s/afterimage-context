# Security Policy

Afterimage is designed around private personal context. Please treat security issues seriously.

## Reporting a vulnerability

Do not publicly disclose sensitive security issues before they are assessed.

Use GitHub's private security advisory mechanism for this repository when available. If that mechanism is unavailable, open a minimal issue without secrets or personal data asking the maintainers for a private reporting channel.

## Never include

- passwords or API keys
- private memory content
- personal identifiers
- authentication tokens
- private logs containing user data

## Security priorities

- Local-first storage
- Least-privilege integrations
- Explicit permissions
- Safe import/export
- Secure deletion
- No hidden collection of memory content
