# Getting help with Afterimage

Before opening an issue:

1. Check [`START_HERE.md`](START_HERE.md) if you want to contribute.
2. Check [`CONTRIBUTING.md`](CONTRIBUTING.md) for development guidance.
3. Check the existing issues for known problems.
4. Use GitHub Discussions for questions, experiments, and larger product ideas.

## Bug reports

Include:

- what you expected
- what happened
- browser and OS
- route or feature involved
- reproduction steps
- console/build errors when relevant

Do not include private memory contents, credentials, tokens, or personal data.

## Security

Do not publish sensitive security details in a public issue. Use the repository's security reporting mechanism where available.

## Product ideas

Explain the context that makes the idea useful. Afterimage prioritizes relevance, explainability, local-first behavior, accessibility, and calm interaction over engagement mechanics.
