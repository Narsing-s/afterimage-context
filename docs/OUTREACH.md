# Afterimage Outreach Kit

Afterimage is an open-source experiment in **contextual memory**: a memory returns when its context becomes relevant again.

Use these messages when sharing the project. Keep claims accurate and avoid describing the MVP as semantic AI or surveillance software.

## Short description

> Afterimage is a local-first contextual memory layer for your future self. Instead of reminding you at a fixed time, it lets you attach a return condition and bring a memory back when similar context appears.

## GitHub post

> I’m building Afterimage — an open-source experiment around a simple idea: **what if software remembered something because the situation became relevant again, rather than because a timer fired?**
>
> You can capture a decision or piece of knowledge, define when it should become relevant again, and test contextual resurfacing locally.
>
> The project is local-first, explainable, and deliberately quiet: no ads, streaks, hidden browsing-history collection, or silent remote memory storage.
>
> Looking for contributors interested in context matching, privacy, browser extensions, accessibility, Android, UX, and evaluation research.
>
> Start here: https://github.com/Narsing-s/afterimage-context/blob/main/START_HERE.md

## Contributor invitation

> Want a small open-source contribution? Afterimage has beginner-friendly missions for keyboard accessibility, local memory tests, “Why now?” explanations, Chrome/Edge compatibility, mobile UX, evaluation datasets, and contributor docs.
>
> Start with `START_HERE.md` and choose one focused issue.

## What not to claim

Do not describe Afterimage as:

- a surveillance or background-monitoring product
- a fully autonomous semantic-memory AI
- a replacement for calendars or task managers
- a service that uploads personal memories to a remote database

The current product intentionally uses local, explainable prototypes and explicit user-controlled context.

## Community rule

Promotion should attract people who care about the underlying problem, not maximize clicks. Prefer technical discussion, real scenarios, reproducible experiments, and useful contributor conversations over engagement bait.
