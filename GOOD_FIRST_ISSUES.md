# Good First Issues & Contributor Missions

Welcome. You do not need to be an Afterimage expert to contribute.

## 🟢 Start here

- Improve README examples
- Add accessibility labels
- Improve responsive layouts
- Add tests for local memory behavior
- Improve empty states
- Add keyboard navigation

## 🧠 Context Explorer

- Design a simple return-condition schema
- Build keyword/context matching experiments
- Measure false-positive resurfacing
- Propose relevance scoring

## 🔐 Privacy Engineer

- Research local encrypted storage options
- Design export/import format
- Review permission boundaries
- Document threat models

## 📱 Android Builder

- Prototype the Android capture flow
- Design offline-first storage
- Explore safe contextual signals

## 🌐 Browser Builder

- Prototype browser capture
- Design permission UX
- Build context extraction experiments without collecting unrelated browsing history

## 🎨 Experience Designer

- Design resurfacing cards
- Improve the “Why now?” explanation
- Create calm notification concepts

## 🧪 Reality Tester

Try scenarios such as:

1. Making a purchase decision
2. Choosing a technology stack
3. Comparing hosting providers
4. Planning a trip
5. Repeating a difficult workflow

Report where the memory should return, should not return, or needs more context.

## Issue labels

Suggested labels: `good first issue`, `help wanted`, `context-engine`, `privacy`, `android`, `browser`, `design`, `docs`, `testing`.
